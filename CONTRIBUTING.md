# Contributing

Keep this repository an independent sample demo. Never add real customer data, release credentials, API keys, production controls, or claims of measured results.

Run `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:e2e`, and `npm run build` before submitting a change. Changes to launch rules need focused logic tests and a browser workflow test. Preserve visible keyboard focus, descriptive control labels, and narrow-screen usability.

Document proposed metrics as targets until research or production evidence exists.
